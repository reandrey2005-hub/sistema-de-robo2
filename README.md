# SENTINEL — Sistema de Alarma para Paquetes

Dashboard web inspirado en un sistema de seguridad para paquetes dejados en el exterior de una vivienda.

## Escenario
1. El repartidor deja el paquete en la entrada.
2. La cámara detecta el paquete.
3. Una persona se acerca desde el exterior.
4. El sistema detecta movimiento.
5. La persona toma el paquete y se dirige hacia la calle.
6. SENTINEL genera una alerta y registra el evento.

## Archivos
- `index.html` — interfaz principal.
- `styles.css` — diseño oscuro estilo panel de seguridad.
- `script.js` — botones, simulación de robo, eventos y reloj.
- `assets/dashboard-referencia.png` — referencia visual.
